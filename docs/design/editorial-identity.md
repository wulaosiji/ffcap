# ffcap.cn 同源异形视觉身份（2026-10-31）

与 UniqueBase 同家族、不同产品：UB 是可查询公司库；ffcap 是研究刊与资本门面。

废止 2026-10-24 紫纸 / UniqueBase 居中克隆表。首页不再用半句斜体点缀、目录 pill 墙或 `[01 / 05]` 装饰序号。

## Token

| 名 | Hex | 角色 |
|---|---|---|
| paper | `#f7f6f1` | 略暖纸底 |
| ink | `#1a221c` | 正文 |
| muted | `#5c6758` | 导语 / 元信息 |
| rule | `#ddd8cc` | 编辑细线 |
| accent | `#3f6b52` | 链接 / 焦点点缀，不大面积铺色 |
| button | `#1e3328` | 近黑绿主钮 |
| focus | `#4e8766` | 焦点环 |

不做：陶土橙、酸绿黑底、紫回流、彩虹阴影卡。

## 字体

- Display / 首页 H1 与主要分区标题：Georgia（或宋体衬线栈）整句，字重 400，tracking -0.02～-0.03em
- UI / 正文 / 导航：Segoe UI + 中文黑体栈
- 元信息 12px sans；默认不用全大写疏字距 eyebrow

## 首页结构

- Hero 左文右器（约 7:5）：左侧衬线标题与导语，右侧搜索 / 最新一篇 / 给 AI
- 三个研究方向 hub 保留 01–03
- 其余分区用句子标题，不用编号装饰
- 不复制顶栏的 pill 行

## 底纹与封面（2026-10-31）

全站两层不要叠成一张图：底纹是淡墨等高线，封面是已有的暖色手绘插画。规则、色板和生图 prompt 见 [unified-visual-20261031.md](./unified-visual-20261031.md)。

- 底纹只走现有 token：paper `#f7f6f1`、ink `#1a221c`、muted `#5c6758`、accent `#3f6b52`。线的透明度 8–18%，阅读列保持实色纸。
- 不把封面高斯模糊成整页背景，不把陶土或紫色设成主色。
