# Settlement assets

Self-hosted assets for the approved local third-person settlement. Keep optimized
runtime textures here, source/license records in ASSET_SOURCES.md, and original
large reference renders only in the project's private design-verification folder.
Do not place game exports, secret data, or unlicensed Sky assets here. Cloud sky is
original image generation; all visible architecture and the character are actual
3D meshes. Screenshots must never be substituted for playable geometry.
